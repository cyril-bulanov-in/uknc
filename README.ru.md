# UKNC Web (Электроника МС 0511)

[![CI / Tests](https://github.com/ТВОЙ_АККАУНТ/uknc/actions/workflows/basic-ci.yml/badge.svg)](https://github.com/ТВОЙ_АККАУНТ/uknc/actions/workflows/basic-ci.yml)

Нативные браузерные ремейки классической экосистемы советских учебных компьютеров УКНЦ (Электроника МС 0511) и семейства БК.

В отличие от традиционных хардверных эмуляторов, требующих образы ПЗУ и сложную настройку, этот проект воссоздает классический терминал ОС (RT-11) и легендарные ретро-игры («Клад», «Вертолет», «Тропа») напрямую на TypeScript и HTML5 Canvas.

## Особенности
* **Кроссплатформенность:** Идеально работает на десктопах, планшетах и смартфонах.
* **Без тяжелой эмуляции:** Чистая логика на TypeScript, стилизованная под ностальгическую 8-уровневую монохромную палитру.
* **Поддержка мобильных устройств:** Нативная интеграция мобильной клавиатуры для комфортного ввода команд прямо на Canvas.

## Разработка
Проект использует [Vite](https://vitejs.dev/) и строгую типизацию TypeScript.

```bash
# Установка зависимостей
npm install

# Запуск локального сервера для разработки
npm run dev

# Сборка готового проекта для продакшена
npm run build
```
